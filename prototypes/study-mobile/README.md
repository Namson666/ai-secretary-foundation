# 拾语 · Android 英语学习界面预览

本阶段供用户确认界面与交互。桌面显示手机框；窄屏充满屏幕。原型是独立静态网页，**不构建 APK，不实现或连接 Flutter 学习业务**。

## 本地运行

在本目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173/ 。无需安装依赖或构建。

## 可以操作

- 今日：学习入口、静音条件、样例任务计数。
- 学习：主动回忆、拼写、听辨；先独立回忆声明/提交，再核对答案。揭晓后才想起或借助提示的记录不能作为独立回忆。
- 词书与资料：样例词搜索、个人文本匹配。词条与题目为手工样例，没有复制商业词库。
- 教练：占位数字人、绿/红对称圆形模拟通话、文字指令与模拟语音、收录目标冻结、对象澄清、操作撤销。
- 复习：已加入待安排 / 已安排 / 暂停 / 自练完成。撤销只撤销本次贡献，保留其他贡献与练习历史。
- 计划：每日时间、手动/辅助/托管方式；分别执行保存复习点与确认安排。
- 考试：作答、交卷待评分、模拟评分完成、发布演示结果。发布之前不显示参考答案。
- 我的：演示数据查看、重置、静音与发音增强状态。

建议走一遍：今日学习 → ship → 模拟“这个词明天练发音” → 把当前焦点换成 journey → 加入时对象仍为 ship → 计划确认明天 19:30 → 复习中跟读或撤销。

## 明确边界

所有页面常驻“交互预览 · 样例数据”。状态使用浏览器 localStorage，仅保存本演示。存储不可用时退回内存并提示，绝不声称已经提交真实学习服务。

朗读仅用浏览器 speechSynthesis。播放结束后才允许记为听辨；打开文本则改记阅读补练。静音不会把口语或听辨标成完成。语音输入与通话是模拟，不申请麦克风权限、不录音、不调用 ASR、LLM、TTS 云服务。数字人为 SVG 占位。

SOE 默认关闭，不产生发音分数；没有 key 仍能完成基础界面演示。FSRS、调度、学习数据库、真实领域回执、通知、导入、同步与 Android 手机验收均未实现。

## 模块边界与验证

`src/pages/` 每页独立；`app.js` 装配路由与动作，`content.js` 仅样例内容，`state.js` 管理演示存储，`services.js` 提供演示命令，`agent-intent.js` 解析有限样例指令。UI 与模拟教练共用命令入口。删除页面需在装配表和导航/入口同时移除；不影响 Flutter 代码。

```sh
npm test
find src -name '*.js' -print0 | xargs -0 -n1 node --check
```

CI 独立检查原型语法与状态契约，不安装 Flutter 或大型浏览器依赖。验证与交接见 `VALIDATION.md`、`HANDOFF.md`。不生成截图、录音、node_modules、构建 bundle 或 APK。

# 拾语 · 英语学习手机界面预览

可点击操作的独立网页。桌面显示手机框，窄屏充满屏幕，默认黑色主题，可切换浅色。当前用于确认界面与交互，尚未实现 Flutter 学习业务，不构建 APK。

## 本地运行

无需安装依赖或构建，在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173/ 。检查：

```sh
npm test
find src -name '*.js' -print0 | xargs -0 -n1 node --check
```

CI 只执行原型语法与契约检查，不安装 Flutter 或浏览器依赖。本目录没有运行时依赖，无需为依赖审计安装软件包。

## 页面与交互

五项导航为今日、选词、统计、AI、我的。计划、复习点、考试、学习偏好及语音设置各有独立入口。

- 今日：复习与新学上限、到期任务、静音、学习入口。待安排和未来任务不计入今天到期；暂停及标熟知的词排除自动队列。
- 选词：四本真实词库，全书搜索、未选/已选/全部/字母索引、每页最多40行，逐词/搜索内字母组/顺选/随机勾选，确认才保存。切书只切范围，不自动加入全书；同书搜索和分页保留草稿，跨书清未确认草稿并提示。已选状态与历史跨书共享。
- 学习：英→中/中→英互猜，遮挡和点击揭晓，朗读、拼写、听辨、例句、收藏及笔记。揭晓前声明想起才能核对后独立自评；揭晓、提示或中→英播放目标词后，不能登记独立成功。可明确选择忘记；缺提示/例句不补造。有效本次学习会话在刷新后恢复，无会话回今日；不会默认全词库。未确认的词不能进入学习队列。
- 统计：遗忘曲线、学习情况、记忆持久度，可切时间范围、图例和点位。科学曲线与持久度始终是示例；学习情况可切当前浏览器尝试。
- AI：普通对话与视频聊天两个模式；导师预览素材、文字、模拟按住说话/上滑取消，视频聊天可全屏或缩小，有静音/扬声器/结束控件。不申请麦克风或摄像头权限。
- 计划与复习：冻结对象→加入待安排→确认明日安排→练习。撤销只移除本次贡献，保留其他贡献和历史。预算、每日量、方向与顺序可调整。
- 考试：作答→待评分→模拟评分完成→发布结果。发布前隐藏答案和成绩。
- 设置：主题、浏览器朗读口音/速度、语音入口、本地 ASR 档位和模拟状态/重试。状态不代表下载安装；ASR 不等于发音评分。

## 词库来源与演示边界

真实预设为日常高频1000、高中基础精选1500、四级核心精选1500、六级核心精选1500，共享2468个不同词头，来自固定版 ECDICT，MIT许可。范围、整理规则与哈希见 [词库溯源](assets/vocabulary/README.md)。它们是公开词频和标签的核心精选，不声称完整覆盖现行考试大纲。

原有18词的手工例句作为独立界面示例补充，其中6个词头在核心精选之外，总可查询词条2474。释义与例句来源分开标注；缺音标、例句与提示保持缺项。词典仅存单份派生模块，未保留65MB源CSV或下载缓存。

全局显示“学习记录为演示”。localStorage保存本演示的词状态、笔记、尝试和计划，sessionStorage仅恢复当前学习界面；存储被禁止时保持可用并提示。恢复不会继承音频播放授权。重置只清本原型 namespace。保存不等于真实学习数据库或领域服务提交。

朗读仅用浏览器 speechSynthesis。听辨须本题音频播放结束，展开文本改记阅读补练。静音不会完成听辨或口语。导师素材和语音/视频通话均为模拟；不调用真实 ASR、LLM、云TTS或数字人SDK。

SOE默认关闭，无key不阻断基础流程，不产生发音分数。FSRS、学习数据库、真实调度、通知、云同步及Android真机均未进入本阶段实现和验收。

## 模块结构与清理

`src/pages/`逐页独立；`app.js`装配路由和生命周期；`content.js`装配词典/独立例句；`vocabulary-source.js`是离线词典；`state.js`管演示存储；`learning-session.js`管小型界面恢复；`services.js`与`study-services.js`是演示命令/查询；`statistics.js`隔离图表数据；`coach-interactions.js`隔离模拟语音/通话状态。

删模块需同时删注册、导航和各入口。真实业务接入应替换演示服务，不能把演示尝试当学习事实。验证与交接见 `VALIDATION.md`、`HANDOFF.md`。不生成测试截图、录音、node_modules、构建bundle或APK。

# 预设词库来源与范围

这四本词书由 ECDICT 公开词典数据整理，提供可以实际查询和练习的英文词头、音标与中文释义。它们是核心精选，不宣称完整覆盖现行考试大纲，也不是墨墨或出版社商业教材的复制品。

## 整理规则

| 词书 | 范围 |
| --- | --- |
| 日常高频 1000 | 正整数 `frq` 排序，缺失时使用正整数 `bnc`；从符合词头及中文释义条件的记录中选取前 1000 项。 |
| 高中基础精选 | `gk` 标签内按上述词频排序选取最多 1500 项。 |
| 四级核心精选 | `cet4` 标签内按上述词频排序选取最多 1500 项。 |
| 六级核心精选 | `cet6` 标签内按上述词频排序选取最多 1500 项。 |

只收录包含英文字母及内部连字符/撇号的单词词头，并要求中文释义非空；本次不把多词短语、数字条目或没有中文释义的条目算入精选。精确词数、上游标签原始计数、模块尺寸和 SHA-256 见 `manifest.json`。

同一个规范小写词头只保存一份条目，各词书通过同一 `id` 引用，切换词书不会另建或清空学习历史。本次合并的是词头而不是经过语言学审定的跨词头义项；源记录的中文释义分行保留，不声称已完成义项消歧或中英逐项对齐。

## 资产与展示约定

单份派生数据位于 `../../src/vocabulary-source.js`，以三个静态数组导出：`vocabularyWords`、`vocabularyBooks`、`vocabularySources`。运行时不访问上游网站、不下载词典，不重复保存另一份完整 JSON；同目录只保留许可与溯源小文件。生成过程中流式读取原文件，没有保留 65 MB 原始 CSV 或下载缓存。

`meaning` 是来源中文释义，`definition` 是来源英文释义；`ipa` 或词性缺失时保留空值。上游 README 的例句和音频字段注明待添加，因此这些条目中的 `example`、例句 `translation`、`hint` 留空，页面应显示“未提供”，不能为全部词条生成伪造例句或权威助记。现有 18 个手工示例的例句可作为独立补充内容覆盖同词，但必须与 ECDICT 释义来源区分。

词典文字应按纯文本转义后呈现。词书 `ids` 是可浏览范围，不能等同于用户已选词或已安排的任务；只有用户确认选词后才加入其学习范围。学习服务、FSRS、语音识别及发音评测是否实现，须按实际代码另行说明。
